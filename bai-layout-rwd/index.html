Tạo layout với Responsive Web Design

Responsive Web Design giúp trang web tự động thay đổi bố cục để phù hợp với kích thước màn hình.

HTML

HTML được sử dụng để tạo cấu trúc cho trang web.

CSS

CSS giúp định dạng giao diện và xây dựng bố cục responsive.

RWD

Media Queries giúp thay đổi giao diện dựa trên kích thước màn hình thiết bị.

Nội dung chính

Trên màn hình desktop, bố cục hiển thị sidebar trái, nội dung chính và sidebar phải trên cùng một hàng.

Khi màn hình nhỏ hơn, các khu vực sẽ tự động thay đổi kích thước hoặc chuyển xuống hàng mới.
