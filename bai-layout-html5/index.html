Giới thiệu về HTML5

HTML5 cung cấp các thẻ ngữ nghĩa giúp xây dựng cấu trúc website rõ ràng và dễ hiểu hơn.

Các thẻ thường sử dụng để tạo bố cục gồm header, nav, section, article, aside và footer.

Ứng dụng CSS trong thiết kế web

CSS được sử dụng để thiết lập màu sắc, kích thước, khoảng cách và cách sắp xếp các phần tử.

Trong bài tập này, CSS Grid giúp chia bố cục thành khu vực nội dung chính và sidebar.

Lợi ích của Semantic HTML

Semantic HTML giúp trình duyệt, công cụ tìm kiếm và công nghệ hỗ trợ hiểu rõ vai trò của từng phần nội dung.
