CSS grid-gap Property

Thuộc tính grid-gap được sử dụng để thiết lập khoảng cách giữa các hàng và các cột trong CSS Grid.

Ví dụ 1: grid-gap: 20px

grid-gap: 20px;

Khoảng cách giữa các hàng là 30px, khoảng cách giữa các cột là 10px.

Ghi chú: gap

gap: 30px 10px;

Trong CSS hiện đại, gap thường được sử dụng thay cho grid-gap và hoạt động với cả Grid và Flexbox.
